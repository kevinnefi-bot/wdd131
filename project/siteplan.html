Documento de Planificación del Sitio Web

WDD 131: Dynamic Web Fundamentals - Proyecto Final

1. Nombre del Sitio (Site Name)

Nombre propuesto: Club de Ciclismo Urbano

Descripción: Este nombre representa de forma directa una comunidad enfocada en promover el uso seguro, recreativo y ecológico de la bicicleta en zonas urbanas.

Logo de referencia: Se ubicará en la carpeta project/images/logo.webp.

2. Propósito del Sitio (Site Purpose)

El sitio web funciona como un centro de información regional para ciclistas urbanos[cite: 6]. Ofrece recomendaciones de rutas seguras, consejos de mantenimiento mecánico básico para bicicletas y un formulario interactivo de membresía[cite: 6].

3. Escenarios de Usuarios (Scenarios)

Las siguientes preguntas guiarán el contenido y resolverán las dudas principales de nuestro público objetivo[cite: 6]:

  • ¿Cuáles son las rutas más seguras para ir en bicicleta al centro de la ciudad?[cite: 6]
  • ¿Dónde puedo encontrar el formulario para unirme a las rodadas nocturnas y contactar a los directores del club?[cite: 6]

4. Esquema de Colores (Color Schema)

Se utilizará una paleta de colores con alto contraste que cumple con los estándares de accesibilidad (WCAG AA):

  • Azul Oscuro (#0d3b66): Usado para encabezados principales, cabecera y pie de página[cite: 1, 6].
  • Naranja Acento (#e36414): Usado para resaltar líneas divisorias, elementos interactivos y enlaces en hover[cite: 1, 6].
  • Texto Principal (#2b2b2b): Usado en párrafos para garantizar una lectura cómoda y limpia[cite: 1].

5. Tipografía (Typography)

Se seleccionaron fuentes modernas de Google Fonts para estructurar el sitio[cite: 2, 6]:

  • Encabezados (Headings): "Montserrat" - Una fuente sans-serif geométrica que aporta modernidad y fuerza visual a los títulos.
  • Cuerpo de texto (Body): "Roboto" - Excelente legibilidad en dispositivos móviles y de escritorio para párrafos e interfaces web.
